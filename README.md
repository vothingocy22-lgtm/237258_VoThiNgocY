## 2. Mô tả ứng dụng
Hệ thống Quản lý Nhân sự là ứng dụng Web Fullstack cho phép quản lý thông tin nhân viên trong doanh nghiệp.
- **Tính năng chính:**
  - Xem danh sách nhân viên.
  - Tìm kiếm nhân viên theo mã nhân viên hoặc họ tên.
  - Thêm nhân viên mới vào hệ thống.
  - Chỉnh sửa thông tin nhân viên.
  - Xóa nhân viên khỏi hệ thống.

---

## 3. Công nghệ sử dụng
- **Frontend:** React (Vite), HTML5, CSS3, JavaScript (ES6+), Docker.
- **Backend:** Node.js, Express.js, Mongoose, Docker.
- **Database:** MongoDB Atlas (Cloud Database).
- **Deployment & Cloud:** Render (Web Service), Docker Hub, GitHub.
